# Immich 3.3.5 security derivative

This image preserves upstream **Immich 3.3.5** and its mobile protocol, UI,
plugins, FFmpeg, ExifTool and media libraries. It rebuilds the server and CLI
from source commit `8303cb117e197c700332b33b61b45314c9cc5bb4`, applies a
reviewable dependency/lockfile patch, and updates Debian security packages.
It adds no authentication or application features. No ML image is included.

The source archive, upstream production/development images and pnpm 11.27.1
archive are checksum pinned. The patch is generated by pnpm, not by editing
installed node_modules. Initial installation disables dependency scripts;
only bcrypt and sharp native builds are enabled explicitly, following upstream's
build process. The inherited npm/npx/corepack build tools are removed from the
runtime image; Node, application binaries and the rebuilt CLI remain available.

Nodemailer crosses a major version. Its Node >=20 requirement is satisfied by
upstream Node 24.22.1; the ordinary transport/rendering/attachment API is tested.
Pilot SMTP notifications remain disabled. Do not enable production SMTP without
checking its actual server/TLS/auth configuration. Zod is covered by a complete
server build and live validation of signup, login and multipart upload.

Zod's newer JSON Schema output includes a root self-reference and a separate
definition. nestjs-zod 5.5.0 incorrectly treats that as two conflicting schemas,
preventing startup. New nullable type unions also confuse Nest Swagger. A
pnpm-managed adapter patch restores inline named roots and equivalent `anyOf`
unions before Nest processes them, in both ESM and CJS. Duplicate-schema checks
remain strict; request validation is unchanged. Tests check named queries,
nullable fields, rejection of genuine conflicts, complete startup and all
references in the published OpenAPI document.

The native media libraries dynamically link the distribution's Brotli decoder;
this differs from Node's bundled decoder, already fixed in upstream Node 24.22.1.
An OS package version alone does not establish that every media codec is safe.
Full scans retain unfixed findings for review.
See [the pilot risk review](security/REVIEW.md); this is not a zero-CVE image.

## Runtime and verification

Run as UID/GID **1000:1000** with `/data` writable and persistent; drop all
capabilities and set no-new-privileges. Keep port 2283 behind a trusted private
reverse proxy. This image's non-root default does not provision host directories.
Use dedicated `postgresql-immich` with UID 1001; its data mount is
`/var/lib/postgresql/pgdata`. Set database/cache credentials privately.

```sh
make -C ../postgresql-immich build-local
make build-local
make test
make scan
```

`make test` uses an isolated internal network and disposable volumes. It runs the
database and bounded, non-root application, checks migrations and UI/API version,
compressed JSON login, authenticated WebSocket, mail composition, native SVG/JPEG,
upload, byte-identical original download and thumbnail generation. ML, geocoding,
maps and transcoding are disabled in the test fixture. No production data or
credentials are used. The PostgreSQL image has additional restart/restore tests.

Native pnpm audits use each deployed/pruned lockfile and block HIGH/CRITICAL
findings. Unrelated docs/web development projects are not shipped or built here.
CI retains native audit reports, full image findings and a CycloneDX SBOM, and
blocks fixable HIGH/CRITICAL image findings before registry login. It transfers
the exact tested image to a separate publication job and uses a unique tag; pin
the resulting registry digest. Weekly checks do not publish automatically.

Keep matching database/media backups. Stop the service and retain data if the
pilot fails; after migrations/uploads, revert using a matched restore rather
than assuming an older image can read the current database. Keep source originals
until the independent backup/restore acceptance has passed.

## Maintenance and source

Review weekly scans and upstream releases. Regenerate the patch using the pinned
pnpm version and `install --lockfile-only --ignore-scripts`; review every lockfile
change. Replace the derivative with upstream once equivalent fixes pass these
runtime tests. The AGPL source is upstream's exact source plus the committed patch
and Dockerfile; preserve the license and provide these sources with distribution.
